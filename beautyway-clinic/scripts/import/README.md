# Импортёр контента bwclinic.ru

Пайплайн переноса. Работает по шагам, каждый шаг перезапускается независимо
и не требует повторного скачивания.

| Шаг | Скрипт | Что делает |
| --- | --- | --- |
| 1 | `crawl.mjs` | Скачивает страницы из sitemap. Одно соединение, пауза 800 мс, докачка с места обрыва. |
| 2 | `extract.py` | Разбирает HTML в `extracted.json`: title, description, canonical, H1, разделы, прайс, FAQ, изображения, связи. |
| 3 | `build_data.py` | Типизированные данные в `src/data/generated/*.json` + медицинская редактура формулировок. |
| 4 | `fetch_assets.py` | Локальные копии изображений (без хотлинка), 350 мс между запросами. |
| 5 | `fetch_videos.py` | Постеры видеоотзывов + пережатие 6 роликов через ffmpeg. |
| 6 | `../optimize-media.mjs` | AVIF + WebP в нужных размерах через sharp. |
| 7 | `make_inventory.py` | `CONTENT_INVENTORY.md` и `REDIRECT_MAP.md`. |
| — | `contrast.py` | Проверка контраста палитры по WCAG. |

## Вежливость к серверу

Импортёр не создаёт нагрузки: одно соединение, паузы между запросами,
резюмируемость, честный User-Agent. Полный проход по 611 URL занимает
около восьми минут. Повторный запуск скачивает только недостающее.

## Что переносится

Контент, а не разметка. HTML-шаблоны, CSS, скрипты, счётчики, GTM, cookies
и tracking ID исходного сайта в проект не попадают.
