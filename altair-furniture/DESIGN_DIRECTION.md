# DESIGN_DIRECTION — Альтаир

Мебель на заказ, Махачкала. «Лаборатория мебели».

## 1. Brand interpretation

Альтаир — производственная мебельная мастерская (заявляет работу с 2000 года, требует
подтверждения владельцем), позиционирующая себя в Instagram как «лаборатория мебели, где
желания обретают форму». Это не шоу-рум с каталогом моделей, а мастерская полного цикла:
проект под конкретное пространство → расчёт → производство → монтаж.

«Лаборатория» в этом проекте — не sci-fi эстетика, а точность: обмер, чертёж, спецификация
материала, допуск в миллиметрах. Сайт должен читаться как техническая документация к
дорогому объекту — но тёплая, а не холодная, потому что предмет разговора — дом человека.

## 2. Target audience

Жители Махачкалы и Дагестана, которые:
- обновляют кухню/спальню/гардеробную в новой или отремонтированной квартире;
- сравнивают частную мастерскую с федеральными сетевыми студиями (Мария, Фабрика Мебели и т.п.);
- ценят вменяемое соотношение цена/качество и живое общение с исполнителем (это то, что
  реально хвалят в отзывах), а не статусный «люкс ради люкса»;
- принимают решение на телефоне — большинство трафика мобильное.

## 3. Business objective

Заявки на замер/расчёт индивидуальной мебели. Побочная, но обязательная метрика — доверие:
сайт должен снять тревогу «а вдруг это гаражная мастерская», не переигрывая в пафос.

## 4. Primary conversion

CTA `Рассчитать проект` — ведёт к секции брифа (шаги: тип мебели → примерные размеры/помещение
→ контакт). Вторичный канал — WhatsApp с предзаполненным сообщением, зависящим от контекста
(категория, если выбрана). Звонок — третий, наименее акцентный канал.

## 5. Visual concept — «Чертёж без стока»

У нас нет прав скачивать сторонние фото и нет доступа к реальным фотографиям объектов
Альтаира внутри этой сессии. Вместо того чтобы маскировать сток под кейсы (запрещено ТЗ),
сайт целиком построен на **собственной технической иллюстрации**: аксонометрические линии,
разрезы, узлы соединений, координатные сетки — весь визуальный ряд рисуется инлайн-SVG в
графитовой линии 1.5px, как чертёж в масштабе. Фотография — предусмотренный, но не
единственный слой: в data-архитектуре у каждого проекта есть поле `image` со значением
`null` и комментарием `// OWNER_ASSET_REQUIRED`, готовое принять реальный кадр без изменения
вёрстки (aspect-ratio задан заранее).

Это одновременно решает две проблемы: не подделывает реальность и создаёт собственный,
непохожий на конкурентов по репозиторию визуальный язык (ирбис — тёплый чертёж/блюпринт
на серифе с ржавым акцентом; наturel — золото на кремовом; звезда-авто — тёмный янтарь).
Альтаир — графит на светлом камне, гротеск, и один точный акцент.

## 6. Typography direction

- Display / H1–H2: **Bricolage Grotesque** — жирный, слегка эксцентричный гротеск с
  инженерным характером в засечках букв; используется крупно, `text-wrap: balance`.
- Body / UI: **IBM Plex Sans** — нейтральный, отлично читается на кириллице, не «люксовый
  серif по умолчанию».
- Technical (номера проектов, размеры, координаты, лейблы материалов): **IBM Plex Mono** —
  единственный монопространственный элемент на сайте, используется дозированно.
- Fluid scale через `clamp()`, `measure` тела текста 60–72 символа, `text-wrap: pretty`
  для абзацев.

## 7. Color logic

Единая графитово-каменная база + один акцент — «сигнальный красный» (карандаш чертёжника,
которым отмечают допуск/правку), а не «золото ради статуса».

```
--stone      #EFEBE1  фон
--paper      #F8F6F0  поверхность/карточка
--surface-2  #E4DECF  вторичная поверхность, границы блоков
--ink        #16130E  текст, тёмные секции
--ink-2      #241F16  вторичный тёмный (глубокие блоки, footer)
--muted      #6E6A5E  вспомогательный текст
--accent     #B23A2A  сигнальный красный — только для меток/акцентов/фокуса, не для UI-заливок
--accent-ink #F8F6F0  текст на акценте
```

Акцент используется точечно: номера проектов, размерные линии, подчёркивания в hover,
фокус-кольца, статус «в работе». Основные CTA — заливка `--ink`, не цветная кнопка.

## 8. Grid

Desktop 12 колонок, tablet 8, mobile 4, gutter `clamp(16px,2vw,32px)`, `container-wide`
до 1680px. Крупные иллюстрации/цифры сознательно выходят за колонку (bleed), текстовые
блоки — всегда внутри сетки.

## 9. Photography / illustration direction

Нет стоковых фото. Вся графика — инлайн SVG: аксонометрия кухонного модуля, разрез шкафа,
узел петли, координатная сетка гардеробной, силуэт кровати с размерными линиями. Один
источник правды — `src/components/illustrations/*`, переиспользуемые по категориям.
Реальные фото добавляются через `next/image` в уже готовые слоты, когда владелец их
предоставит (см. `OWNER_ASSET_REQUIRED` в data-слое).

## 10. Motion language

- Reveal текста и линий — «дочерчивание»: SVG-линии проявляются через `pathLength`
  (framer-motion), как будто чертёж дорисовывается на экране.
- Смена изображений/иллюстраций в портфолио — clip-wipe, не fade.
- Hover по категориям — сдержанная смена подсветки узла на иллюстрации, без bounce.
- `prefers-reduced-motion` отключает все SVG draw-анимации и parallax, оставляя
  мгновенное появление.

## 11. Information architecture

Одностраничный editorial-опыт с якорями (соответствует конвенции соседних проектов
в репозитории и объёму данных, которые реально можно подтвердить сегодня):

1. Header (прозрачный → плотный при скролле)
2. Hero — чертёж + заявление бренда
3. Proof strip — рейтинг/отзывы/город (числа обновляемые, не хардкод-легенда)
4. Философия лаборатории — почему не каталог
5. Направления (Кухни/Шкафы/Гардеробные/Спальни/Индивидуальные) — index-лента с
   переключением иллюстрации при hover/tap
6. Избранные проекты — editorial-ритм, разная композиция на каждый проект
7. Процесс — вертикальная таймлиния
8. Калькулятор/бриф — форма заявки
9. Отзывы — реальные тексты с Яндекс Карт
10. FAQ
11. Финальный CTA
12. Контакты + карта + footer

## 12. Hero concept

Не «слева текст — справа фото». Полноэкранная композиция: крупная аксонометрическая
SVG-иллюстрация кухонного модуля в разрезе занимает правую/нижнюю часть экрана как
самостоятельный технический чертёж (с размерными линиями и подписями материалов), слева
и сверху — архитектурно расставленный текст (эйдент, H1, CTA), внизу — тонкая техническая
строка (город, координаты мастерской, номер листа чертежа «01/06»). На мобильном
иллюстрация уходит под текст как full-bleed нижний слой уменьшенного масштаба.

## 13. Portfolio presentation

Каждый проект — самостоятельная композиция (крупная иллюстрация 65–75vw, затем узкая
двухколоночная пара деталей, затем full-bleed). Подпись: номер (mono), тип объекта,
район/город, короткая задача клиента. Материалы/сроки/год — только если подтверждены;
иначе поле не рендерится (не заглушка, а honest omission).

## 14. Mobile strategy

Отдельная композиция hero (не сжатая десктопная): иллюстрация уменьшается и уходит вниз
экрана, текст занимает верхние 60%. Категории — вертикальная лента вместо hover-переключения
(тап разворачивает иллюстрацию). Калькулятор — по одному вопросу на экран (шаговый), а не
длинная форма. Sticky нижняя CTA-панель (звонок / WhatsApp / рассчитать) на всех экранах.

## 15. Things we explicitly refuse to do

- Сток-фото, выданное за объект Альтаира.
- Золотой/латунный акцент «для статуса».
- Rounded-cards 3×2 сетка направлений/отзывов.
- Glassmorphism без функциональной причины.
- Одинаковая ширина/ритм секций.
- Придуманные сроки/цены/гарантии, которых нет в исходных данных.
- Автозапуск WhatsApp/звонка без действия пользователя.
