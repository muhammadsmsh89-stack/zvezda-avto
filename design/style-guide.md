# AI MONEY START — Style Guide

## Brand

**AI MONEY START** — wordmark набран заглавными буквами Liberation Sans Bold с увеличенным трекингом (letter-spacing: 0.04em). Логотип-иероглиф не создаётся намеренно — продукт про систему действий, не про визуальный брендинг. Wordmark всегда идёт на фоне `--bg` с текстом `--ink`, акцентная точка после AI MONEY START может быть закрашена `--accent`.

## Visual direction

Premium tech · editorial · minimal · practical. Много пространства, крупная типографика для номеров модулей, карточки вместо сплошного текста, один акцентный цвет.

## Color

| Токен | Значение | Использование |
|---|---|---|
| `--bg` | `#F7F6F3` (off-white) | фон страниц |
| `--surface` | `#FFFFFF` | карточки, таблицы |
| `--ink` | `#111111` (near-black) | основной текст |
| `--ink-soft` | `#4A4A46` | вторичный текст, подписи |
| `--line` | `#DEDCD5` | границы, разделители |
| `--accent` | `#0057FF` (Electric Blue) | единственный акцент |
| `--accent-soft` | `#E8EEFF` | подложки под акцентные бейджи |

**Почему Electric Blue, а не Acid Green:** продукт про переговоры с бизнесом, деньги, доверие — синий читается как «профессионально и спокойно» на печатной странице и в PDF-чек-листах, тогда как кислотный зелёный на белой/almost-white бумаге в печати легко уходит в «маркер-кричалку» и хуже работает в длинных документах (60–80 страниц). Синий используется системно и единолично — если в будущем понадобится второй акцент (например, статус WON), использовать оттенок того же синего темнее/светлее, не вводить второй цветовой хайлайт.

## Typography

Единая гарнитура — **Liberation Sans** (Bold для заголовков и номеров модулей, Regular для основного текста, Italic для подписей/цитат) и **Liberation Mono** для промптов, кода, plaintext-шаблонов сообщений. Обе гарнитуры лицензированы под SIL Open Font License, поставляются локально в `src/final-product/assets/fonts/` и встраиваются в PDF через `@font-face` с относительным путём — сборка не зависит от интернета и системных шрифтов пользователя, что снимает любые риски «PDF embedding reliability». Обе гарнитуры имеют полное кириллическое покрытие.

Шкала: H1 модуля — 40pt Bold; H2 секции — 20pt Bold; body — 10.5pt Regular, line-height 1.5; caption/label — 8.5pt, uppercase, letter-spacing 0.08em, `--ink-soft`.

## Design elements

Использовать: крупные заголовки, progress-маркер (01/11 … 11/11), карточки с рамкой `--line` и левым акцентным бордером у примеров, нумерованные шаги, таблицы с чередующимся фоном строк, чек-боксы (☐), тонкие разделители, code/prompt-карточки на `--surface` с моноширинным шрифтом.

Не использовать: изображения роскоши/денег/крипто-графику, fake-дашборды, случайные 3D-фигуры, стоковых «бизнесменов», избыточные градиенты, более одного неонового акцента.

## Visual motif

**PROGRESS TO FIRST CLIENT** — 9-точечная шкала (Service · Skill · Proof · Offer · Leads · Outreach · Sales · Delivery · Growth), используется на обложке Guide, в верхнем колонтитуле каждого модуля (текущая точка подсвечена `--accent`) и на финальной странице Day 30 Review.

## Print / PDF technical rules

Формат A4, поля 20mm (18mm корешок для брошюровки), заголовки не остаются «сиротами» внизу страницы (`break-after: avoid` на H1/H2), таблицы не разрываются посреди строки где возможно (`break-inside: avoid` на строки), нумерация страниц в футере, кликабельное оглавление через внутренние якорные ссылки (`<a href="#module-N">`), внешние ссылки подчёркнуты `--accent`.
