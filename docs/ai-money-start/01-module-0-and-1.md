## WHAT

Сейчас — не обучение. Сейчас — карта всей системы целиком, на 10–15 минут, чтобы дальше не гадать «а что дальше».

## WHY

Ты уже видел(а) десятки роликов про заработок с ИИ. Не хватает не мотивации и не ещё одной теории — не хватает системы, где после каждого шага остаётся конкретный результат: файл, сообщение, цифра в таблице. Это она.

## HOW

Путь состоит из 11 модулей. Каждый модуль = один блок системы = один день или несколько дней в 30-Day Action Plan.

```
MODULE 0   START HERE                                        → сейчас
MODULE 1   Money With AI — за что платит клиент               → День 1 (утро)
MODULE 2   Каталог услуг + Service Score + Starter Services    → День 1
MODULE 3   Выбор своей услуги — Primary + Backup                → День 1
MODULE 4   Освоение услуги за 3 дня                             → Дни 2–4
MODULE 5   Portfolio & Case Builder — 3 кейса                   → Дни 5–7
MODULE 6   Offer Builder                                        → Дни 5–7
MODULE 7   Price Builder                                        → Дни 5–7
MODULE 8   Lead System — где искать, Lead Score, Lead Tracker  → День 8
MODULE 9   Outreach — сообщения, диалог, возражения, сдача      → День 9+
MODULE 10  Scoreboard, отзывы, First Client Checkpoint          → весь месяц, парал.
```

Ключевое правило продукта: **обучение и поиск клиентов идут параллельно, а не последовательно.** Три недели «сначала учусь, потом ищу клиентов» здесь нет — с Дня 9 ты уже пишешь людям, даже если навык ещё не идеальный.

К концу **Дня 7** у тебя обязаны существовать восемь конкретных вещей:

```

☐ 1 выбранная ЦА
☐ 3 демонстрационных кейса
☐ портфолио (кейсы, собранные в одном месте)
☐ оффер
☐ стартовая цена
☐ первое сообщение (черновик)
☐ Lead Tracker (пустой, но готовый к заполнению)
```

Дальше: **День 8** — находишь 15–20 потенциальных клиентов. **День 9** — отправляешь первые сообщения. С этого дня учёба (докрутка навыка, кейсов) и outreach идут одновременно, до конца месяца.

# MODULE 1 — MONEY WITH AI: ЗА ЧТО РЕАЛЬНО ПЛАТЯТ ЛЮДИ

## WHAT

Сейчас ты научишься одной вещи: переводить «я умею пользоваться ИИ» в формулировку, за которую готовы платить. Это займёт 15 минут и одно упражнение.

## WHY

ИИ сам по себе не услуга. Клиент не платит за ChatGPT или Claude — он платит за результат, который решает его проблему. Если ты говоришь на языке инструмента («я использую ИИ», «я умею Claude»), клиент не понимает, что он получит. Если ты говоришь на языке результата («я соберу вам лендинг», «подготовлю 30 постов для Telegram»), он понимает это за секунду.

## HOW

Формула, на которой строится весь продукт:

```
Проблема клиента  →  Результат  →  Услуга  →  ИИ ускоряет производство
```

ИИ здесь — последнее звено, а не первое. Он не то, что ты продаёшь. Он то, что позволяет тебе делать результат быстрее и дешевле, чем без него.

## EXAMPLE

| ПЛОХО (язык инструмента) | ЛУЧШЕ (язык результата) |
|---|---|
| «Я использую ИИ» | «Я сделаю вам презентацию для инвестора» |
| «Я умею Claude» | «Я соберу лендинг вашего бизнеса» |
| «Я генерирую тексты» | «Я подготовлю 30 постов для вашего Telegram» |
| «Я работаю с нейросетями» | «Я оформлю карточки товаров для вашего маркетплейса» |
| «У меня есть промпты для дизайна» | «Я сделаю редизайн главной страницы вашего сайта» |

Разница не в словах ради красоты — разница в том, понимает ли человек, за что платит.

## TEMPLATE

```
Я не продаю [ИИ-инструмент].
Я продаю [конкретный результат] в виде [услуга] для [ниша / тип бизнеса].
```

Пример заполнения:

```
Я не продаю ChatGPT.
Я продаю понятную страницу с ценами и записью в один клик
в виде лендинга для стоматологических клиник.
```

# QUALITY CHECK

**1. Есть ли вода?**
Нет длинных теоретических отступлений. WHY в обоих модулях — 2–3 абзаца максимум. Убраны любые фразы-заполнители («в современном мире», «многие мечтают» и т.п.).

**2. Можно ли что-то сократить?**
Проверено: в Модуле 1 сначала было 6 пар BAD→BETTER — оставлено 5, шестая («Я работаю с промптами» → дубль по смыслу с уже имеющейся) убрана как избыточная. Дальше сокращать некуда без потери примеров, на которых держится HOW.

**3. Есть ли конкретное действие?**
Да в обоих модулях: Модуль 0 — заполнить снимок точки старта; Модуль 1 — переписать 3 фразы по формуле. Оба выполнимы за 5–15 минут, оба дают файл/текст, а не «подумать».

**4. Есть ли готовый шаблон?**
Да: снимок точки старта (Модуль 0) и формула перевода инструмент→результат (Модуль 1) — оба в виде заполняемого бланка.

**5. Понятно ли это человеку без опыта?**
Да: не используется профессиональная терминология без объяснения; формула из 4 слов; таблица BAD→BETTER не требует предзнаний.

**6. Нет ли обещаний заработка?**
Нет. Пример недели 1 (Модуль 0) описывает только процесс и артефакты («готовы 3 кейса», «отправлены сообщения»), не результат в деньгах. Нигде не встречается сумма, срок дохода или гарантия.

**7. Выглядит ли материал как продукт за деньги, а не бесплатная статья?**
Да, за счёт структуры (жёсткий каркас WHAT/WHY/HOW/EXAMPLE/TEMPLATE/YOUR TURN/DONE WHEN), готовых заполняемых бланков и DONE WHEN-гейтов, которых нет в обычном бесплатном посте про заработок с ИИ — это система с проверкой прогресса, а не набор советов.
