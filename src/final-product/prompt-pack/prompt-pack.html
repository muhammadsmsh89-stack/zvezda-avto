Предложи 5 услуг из каталога 15 направлений (лендинги, презентации, лид-магниты, Telegram-контент, сценарии, карточки товара, соцсети, исследования, инструкции, email, визуал, монтаж, автоматизации, аудит, редизайн сайта), которые соответствуют интересам.

Раздел 03

Портфолио

Спринт портфолио: 3 кейса — 7 промптов.

ПРОМПТ 14 — Концептуальный бриф
РОЛЬ
Генератор демонстрационных брифов.
КОНТЕКСТ
Пользователь готовит концептуальный проект для портфолио.
ВВОДНЫЕ
[УСЛУГА], [НИША], [СЛОЖНОСТЬ], [ЦЕЛЬ ДЛЯ ПОРТФОЛИО]
ЗАДАЧА
Сгенерируй реалистичный бриф: бизнес, контекст, аудитория, проблема, цель, результат работы, обязательное содержание, ограничения, критерии успеха, что нельзя выдумывать.
ОГРАНИЧЕНИЯ
Если бизнес реальный и факты неизвестны — оставь как [ЗАГЛУШКА]. Никогда не выдумывай выручку, клиентов, награды, результаты, цены.
ФОРМАТ ОТВЕТА
Бриф строго по перечисленным полям.
ПРОМПТ 15 — Разнообразие кейсов
РОЛЬ
Куратор портфолио.
КОНТЕКСТ
Пользователь должен убедиться, что 3 кейса достаточно различаются.
ВВОДНЫЕ
[ОПИСАНИЕ КЕЙСА 1], [КЕЙСА 2], [КЕЙСА 3]
ЗАДАЧА
Сравни по нише, аудитории, проблеме, результату работы, стилю, сложности — укажи, где кейсы слишком похожи.
ОГРАНИЧЕНИЯ
Не выдумывай факты, цифры, отзывы или результаты, которых нет во входных данных. Если данных недостаточно — пиши «НЕИЗВЕСТНО / НУЖНЫ ДАННЫЕ» вместо предположения.
ФОРМАТ ОТВЕТА
Таблица сравнения + вывод: достаточно ли различий (да/нет) и что изменить.
ПРОМПТ 16 — Критика кейса
РОЛЬ
Ревьюер портфолио.
КОНТЕКСТ
Пользователь хочет проверить кейс перед публикацией.
ВВОДНЫЕ
[ОПИСАНИЕ КЕЙСА]
ЗАДАЧА
Оцени по ясности, бизнес-логике, подаче, достоверности.
ОГРАНИЧЕНИЯ
Сначала назови 3 самых критичных недостатка, не хвали автоматически.
ФОРМАТ ОТВЕТА
3 главных недостатка + краткая оценка по 4 категориям.
ПРОМПТ 17 — Оформление кейса
РОЛЬ
Копирайтер портфолио-кейсов.
КОНТЕКСТ
Пользователь выполнил работу и должен оформить её по формату кейса.
ВВОДНЫЕ
[БРИФ], [РЕЗУЛЬТАТ РАБОТЫ], [КЛЮЧЕВЫЕ РЕШЕНИЯ]
ЗАДАЧА
Собери кейс по полям: название, статус, тип клиента, задача, цель, подход, результат работы, ключевые решения, что демонстрирует кейс.
ОГРАНИЧЕНИЯ
Статус всегда «Концептуальный проект», если это не оплаченный проект. Поле «результаты бизнеса» не используется — только «итог работы».
ФОРМАТ ОТВЕТА
Заполненный кейс по всем полям.
ПРОМПТ 18 — Аудит портфолио
РОЛЬ
Критичный аудитор портфолио.
КОНТЕКСТ

ЗАДАЧА

ОГРАНИЧЕНИЯ
Не придумывай проблемы, которых нет в материале. Не хвали автоматически.
ФОРМАТ ОТВЕТА
Список конкретных замечаний, отсортированный по важности.
ПРОМПТ 19 — Питч на 30 секунд
РОЛЬ
Тренер по питчингу.
КОНТЕКСТ

ПРОМПТ 20 — Детектор выдуманных фактов
РОЛЬ
Контролёр честности портфолио.
КОНТЕКСТ
