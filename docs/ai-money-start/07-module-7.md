# AI MONEY START — GUIDE
## MODULE 7 — OUTREACH ENGINE (черновик, близкий к финальному)

**Формат:** это модуль PDF-продукта, не отдельный курс. Ориентир — 6–8 плотных PDF-страниц Guide. Приоритет: **SCRIPT → ACTION → TRACK → IMPROVE.** Полные библиотеки шаблонов (15 первых сообщений, 12 follow-up, mini-audit примеры и т.д.) вынесены в `07a-module-7-templates.md` — здесь только система и по одному лучшему примеру на каждый механизм.

**Привязка к плану:** День 9. Portfolio, offer, scope, price, ICP, 50 лидов, First 15 и personalization notes уже готовы (Modules 4–6) — Module 7 не создаёт новых материалов для продажи, а учит их отправлять.

---

## WHAT

Отправить первые 15 сообщений, понимать структуру первого касания, персонализировать без эссе, знать, когда показывать портфолио, уметь делать follow-up, не выполнять бесплатно половину проекта, фиксировать всё в Lead Tracker и считать реальную конверсию.

**Главный принцип: первое сообщение не обязано закрыть продажу.** Его задача — получить следующий маленький шаг: ответ, разрешение показать идею, обсуждение задачи, короткий созвон, запрос портфолио.

## WHY

### SECTION 1 — WHY MOST COLD MESSAGES FAIL

«Предлагаю взаимовыгодное сотрудничество» · «Я занимаюсь сайтами, вам интересно?» · «У вас плохой сайт, могу переделать» · «Я молодой специалист, хочу предложить услуги» · «Увеличу продажи с помощью современного сайта».

Проблемы: сообщение про исполнителя, а не клиента · нет конкретного наблюдения · слишком ранняя продажа · слишком длинно · нет понятного next step · неподтверждённые заявления · шаблонность.

## HOW

### SECTION 2 — FIRST MESSAGE FORMULA

```
CONTEXT → OBSERVATION → RELEVANCE → LOW-FRICTION NEXT STEP
```

```
CONTEXT:     «Посмотрел вашу карточку и Instagram»
OBSERVATION: «Увидел, что отдельной страницы под запись сейчас нет»
RELEVANCE:   «Я как раз собираю такие страницы для локального бизнеса»
NEXT STEP:   «Если актуально, могу показать короткую идею, как это можно собрать»
```

Не «вы теряете клиентов» — а «отдельной страницы я не нашёл(нашла)».

### SECTION 3 — THE 4-LINE RULE

Первое сообщение — 2–4 короткие смысловые строки, не коммерческое предложение.

```
TOO LONG:  длинное вступление о себе, опыте, преимуществах ИИ, цене и сроках сразу
BETTER:    «Здравствуйте! Смотрел(а) [КОМПАНИЯ] — [НАБЛЮДЕНИЕ]. Собираю
            [DELIVERABLE] для похожих бизнесов. Если актуально, могу
            показать короткую идею.»
```

Ещё 4 примера TOO LONG → BETTER — в Templates (Section T1).

### SECTION 4 — PERSONALIZATION LEVELS

```
LEVEL 0 — GENERIC              почти одинаковое сообщение всем — использовать минимально
LEVEL 1 — LIGHT                имя/компания + одно реальное наблюдение — для большинства B-лидов
LEVEL 2 — DEEP                 конкретная страница/услуга/контент/timing signal/релевантный
                                кейс — только для сильных A-лидов
```

Не тратить 15 минут персонализации на каждого из 50 лидов — глубина зависит от Score из Module 6.

### SECTION 5 — 15 FIRST-MESSAGE TEMPLATES

Полная библиотека (3 на каждую из TOP 5 Starter Services, с плейсхолдерами [ИМЯ]/[КОМПАНИЯ]/[НАБЛЮДЕНИЕ]/[УСЛУГА]/[РЕЛЕВАНТНЫЙ КЕЙС]) — см. Templates Section T2. Пример (Landing Pages):

```
«Здравствуйте, [ИМЯ]! Смотрел(а) страницу [КОМПАНИЯ] — [НАБЛЮДЕНИЕ]. Я собираю
такие страницы для [НИША]. Если актуально, могу показать короткую идею, как
это можно оформить.»
```

### SECTION 6 — DIFFERENT CHANNELS

| Канал | Подача | Пример |
|---|---|---|
| Telegram / WhatsApp | самое короткое | см. Section 2 формулу как есть |
| Instagram / VK DM | чуть более разговорно | «Привет! Смотрел(а) вашу страницу — [НАБЛЮДЕНИЕ]. Собираю такие [DELIVERABLE] для похожих аккаунтов, было бы интересно показать идею?» |
| Email | Subject + короткий body | Subject: «Идея по странице [КОМПАНИЯ]» / Body: та же формула CONTEXT→OBSERVATION→RELEVANCE→NEXT STEP |
| Freelance Marketplace | сразу больше конкретики — intent уже есть | см. Section 22 |

### SECTION 7 — WHEN TO SEND PORTFOLIO

```
Portfolio should support interest, not replace the conversation.

A. Клиент спросил примеры              → отправить
B. Есть очень релевантный кейс          → можно включить 1 ссылку в первое сообщение
C. Portfolio общий / нерелевантный      → не отправлять сразу
```

Пример фразы: «Конечно! Вот ссылка на примеры: [ССЫЛКА] — там кейс, близкий к вашей задаче.» Ещё 4 варианта — Templates Section T3.

### SECTION 8 — MINI AUDIT / SAMPLE

Наблюдения из Module 6 превращаются в sales asset:

```
OBSERVATION → WHY IT MATTERS → POSSIBLE DIRECTION
```

Пример: «На мобильной версии основной CTA появляется только после нескольких блоков. Я бы протестировал(а) более заметный путь к записи уже на первом экране.» Не «из-за этого вы теряете 30% клиентов». Ещё 4 примера (по остальным Top 5) — Templates Section T4.

### SECTION 9 — FREE VALUE BOUNDARY

```
SHOW THINKING ≠ DELIVER THE PROJECT

Допустимо:            2–3 наблюдения · один rough concept · пример headline · outline · короткий sample
Не допустимо:         полный лендинг · 20 постов · готовая презентация · полный PDF · 30 сценариев
```

### SECTION 10 — THEY REPLIED "INTERESTING"

Не «Цена 30 000 ₽, куда платить?» сразу — сначала понять задачу. Готовые ответы на 5 типичных реакций («Да, расскажите» / «Интересно» / «Что предлагаете?» / «Сколько стоит?» / «Покажите примеры») — Templates Section T5.

### SECTION 11 — 5 DISCOVERY QUESTIONS

```
1. Что хотите получить?
2. Для какой услуги / продукта?
3. Что используете сейчас?
4. Есть ли желаемый срок?
5. Есть ли важные требования?
```

Не анкета подряд — естественный мини-диалог, по одному-два вопроса за раз, встроенные в ответ.

### SECTION 12 — FOLLOW-UP SYSTEM

Молчание ≠ отказ, но спамить нельзя.

```
FOLLOW-UP #1  — короткий, через разумный интервал после первого сообщения
FOLLOW-UP #2  — ещё один контакт
FOLLOW-UP #3  — финальное мягкое закрытие цикла
```

Пример каденции (рабочая модель, не научный факт, можно адаптировать):

```
День 9 — первое сообщение
Дни 11–12 — follow-up #1
Дни 15–17 — follow-up #2
Позже — final / при новом timing signal
```

### SECTION 13 — 12 FOLLOW-UP TEMPLATES

4 gentle + 3 value-based + 2 portfolio + 2 timing-signal + 1 close-the-loop — полный список в Templates Section T6. Пример (gentle): «Привет! Не хочу быть навязчивым(ой) — просто поднимаю сообщение выше, вдруг затерялось.» Никакого «Возможно, вы не увидели моё прошлое сообщение???».

### SECTION 14 — OUTREACH CADENCE

```
DAILY BLOCK:  New Leads + New Messages + Follow-Ups + Replies + Tracker Update
```

Объём (например, 15 новых outreach + follow-ups) зависит от персонализации, канала и доступного времени. **CONSISTENCY > RANDOM BURSTS.**

### SECTION 15 — A/B TESTING

Не менять всё после трёх игноров. MESSAGE A vs MESSAGE B — менять только один элемент за раз: opening, CTA, offer framing или personalization style, не всё одновременно. Копить собственные наблюдения, прежде чем делать вывод — без псевдонаучного минимального sample size.

### SECTION 16 — SCOREBOARD

```
Reply Rate            = Replies / Messages Sent × 100
Positive Reply Rate    = Positive Replies / Messages Sent × 100
Discussion Rate         = Discussions / Positive Replies × 100
Offer Rate               = Offers / Discussions × 100
Close Rate                = Won / Offers × 100
```

Если знаменатель = 0 — метрика пока не считается (Lead Tracker Dashboard из Module 6).

### SECTION 17 — DIAGNOSE THE FUNNEL

| Симптом | Проверить |
|---|---|
| Много сообщений → мало ответов | качество лидов, канал контакта, opening, релевантность, персонализация, ясность оффера |
| Ответы → мало позитивных | need, позиционирование, timing, релевантность оффера |
| Интерес → нет обсуждения | next step слишком большой, ответ слишком длинный, слишком раннее начало продажи |
| Обсуждения → нет офферов | квалификация, ясность, уверенность, понимание scope |
| Офферы → нет продаж | цена, доверие, scope, timing, sales process — подробнее в Module 8 |

### SECTION 18 — WHAT NOT TO DO AFTER 10 IGNORES

Не менять услугу · не удалять портфолио · не снижать цену в 5 раз · не писать всем «скидка сегодня» · не считать рынок мёртвым. Нужно смотреть на данные — 10 сообщений во многих случаях слишком мало для сильных выводов, но универсального sample size здесь нет.

### SECTION 19 — OUTREACH TRACKER FIELDS

Используется тот же Lead Tracker из Module 6, без новой таблицы: Date Contacted, Message Version (A/B/C), Status, Last Reply, Follow-Up Date, Next Action.

### SECTION 20 — 30-DAY OUTREACH ENGINE

```
День 9   — First 15
День 10  — новый outreach + ответы
День 11  — новый outreach + первые follow-up
День 12+ — New Leads + Outreach + Follow-Up + Conversations
```

Outreach не заканчивается после первых 50 лидов — база пополняется, если заканчивается.

### SECTION 21 — WARM OUTREACH

Для знакомых и рекомендаций — не холодный скрипт. Пример: «Я сейчас специализируюсь на [SERVICE] для [TYPE]. Если среди знакомых встретится бизнес, которому актуальна такая задача, буду благодарен(на) за знакомство.» Не просить человека продавать вместо тебя. Ещё 4 варианта — Templates Section T7.

### SECTION 22 — FREELANCE PLATFORM RESPONSE

```
1. Я понял(а) задачу
2. Вот релевантный опыт / concept
3. Вот как бы подошёл(шла)
4. Вот что нужно уточнить
5. Следующий шаг
```

Не «готов выполнить быстро и качественно». 5 примеров по Top 5 услугам — Templates Section T8.

### SECTION 23 — OUTREACH RED FLAGS

Осторожно, если: просят перейти в подозрительный сервис · требуют оплатить «доступ к проекту» · просят выполнить весь проект бесплатно · требуют передать чувствительные аккаунты до договора · задача незаконна · просят подделывать данные · постоянно меняют задачу · отказываются обсуждать scope, но требуют точную цену · создают искусственную срочность вокруг оплаты исполнителем каких-либо комиссий.

### SECTION 24 — FIRST 15 SPRINT

```
1. Открыть First 15 из Module 6
2. Для каждого выбрать: Template · Personalization · Relevant Case · CTA
3. Отправить сообщения
4. Сразу отметить CONTACTED
5. Установить Follow-Up Date
6. Не сидеть и не обновлять мессенджер — перейти к следующей задаче
```

# QUALITY CHECK

**1. Отправит ли человек сообщение после этого модуля?**
Да — Section 24 (First 15 Sprint) даёт прямую последовательность из 6 шагов, DONE WHEN требует фактической отправки 15 сообщений.

**2. Не слишком ли длинные scripts?**
Нет — The 4-Line Rule (Section 3) и полная библиотека шаблонов вынесены в отдельный Templates-файл, чтобы Guide оставался про систему.

**3. Есть ли сообщения под Top 5?**
Да — 15 First-Message Templates по 3 на каждую услугу (Templates T2), плюс freelance-ответы (T8) и mini-audit примеры (T4) тоже по всем пяти.

**4. Отличается ли первое сообщение от предложения?**
Да — Section 9 (Free Value Boundary) и Section 10 прямо разводят «получить ответ» и «закрыть сделку»; цена и полный оффер не встречаются в первом сообщении.

**5. Не обещаем ли неподтверждённые бизнес-результаты?**
Нет — Section 8 (Mini Audit) явно требует Observation→Hypothesis, а не «вы теряете 30% клиентов».

**6. Есть ли нормальный follow-up?**
Да — Section 12–13, 3 раунда + close-the-loop, каденция помечена как рабочая модель, не научный факт.

**7. Нет ли спама?**
Нет — follow-up ограничен 3 раундами с финальным закрытием цикла (Section 12), red flags (Section 23) и правило не менять всё после 10 игноров (Section 18) защищают от навязчивости.

**8. Есть ли free-value boundary?**
Да — Section 9, с явным списком допустимого/недопустимого.

**9. Используется ли Lead Tracker из Module 6 вместо новой CRM?**
Да — Section 19 прямо говорит «используется тот же Lead Tracker, без новой таблицы», добавляется только Message Version.

**10. Можно ли диагностировать слабое место воронки?**
Да — Section 17, таблица «симптом → что проверить» по всем 5 этапам воронки.

**11. Не дублирует ли модуль будущий Sales Module?**
Нет — Section 11 ограничен 5 discovery-вопросами, Section 17 явно передаёт «офферы → нет продаж» в Module 8, здесь только помечены категории (цена, доверие, scope, timing, sales process) без подробного разбора.

**12. Укладывается ли Guide-часть примерно в 6–8 PDF-страниц после нормальной вёрстки?**
Да, по объёму: этот файл содержит систему и по одному примеру на каждый из 24 механизмов, все объёмные библиотеки (15+12+5+5+5+5+5 готовых сообщений) физически вынесены в отдельный Templates-файл — при вёрстке в PDF с обычной плотностью текста и карточками эта часть укладывается в 6–8 страниц.
